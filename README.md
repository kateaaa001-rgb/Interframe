# Interframe
Interframe is an Android gallery utility app.
It reads all local photos and videos on your device, presents media in a short-video-style vertical stream.
You can quickly favorite, delete or skip each media item with simple gestures.

This app helps you clean up storage space while reviewing your old moments.
All media processing runs locally on your device. No media data will be uploaded to any remote server.

Features:
• Load all local images & videos from system gallery
• Vertical stream UI, swipe to browse media, like short video apps
• Quick action: favorite / delete / ignore each frame
• Local-only processing, privacy-first
• Help free storage and review your memories

Warning: This app requires full gallery access permission to enumerate media files.
